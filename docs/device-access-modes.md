# 设备访问：当前开源版本与后续账号版本

更新：2026-09-15。0.1 版本提供免账号设备访问，账号登录相关业务留待后续版本。

## 当前实现

长期访问使用软件生成的连接证书，可手动或按周期轮换；临时访问使用软件自动生成的一次性密码。每台设备只有一份当前长期证书和至多一个未使用的临时密码。当前不提供自定义长期密码。

Mac：设置 → 本机接入与凭据，启停共享、导出/轮换证书、生成/作废临时密码；新建主机选择对应认证方式。独立 Agent 提供相同凭据管理 CLI 和后台服务示例。

临时密码在首次认证成功时持久化消耗，只授权当前 TLS 设备访问。一个访问可包含多个 PTY；关闭最后一个 PTY或断开后旧密码不能重新连接。输入错误不消耗未使用密码；正确密码已验证后响应丢失属于不确定状态，按已使用处理。

未使用密码可设置 1 分钟至 24 小时的有效期，默认 30 分钟。期限只限制建立新访问，不定时切断已经打开的终端。重新生成/作废只处理后续认证，停止共享会关闭当前访问。关闭或重启不会恢复旧密码。

证书默认手动轮换，可设 1–8760 小时周期；运行中的 Agent 执行到期检查。旧证书不能建立新连接，已有授权继续工作。轮换后需重新导出证书，设备 ID 保持不变。

本机共享默认关闭，终端继承 Agent 的系统用户身份；root 服务需由管理员显式安装。具体安全边界、异常处理和限制见 [安全说明](../SECURITY.md)。

## 明确暂不实现

账号注册、登录、刷新令牌、账号绑定、同账号设备发现、跨端设备清单、云端在线/离线设备同步。匿名版不公布全平台设备列表；离线或不可达的手动主机记录仍保留在本机。

后续账号模式可以在设备访问授权处新增独立授权来源，但不能通过客户端传来的账号名称直接放行，也不能把中继准入令牌作为设备所有权。未实现的账号业务不进入当前发布声明。
