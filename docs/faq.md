# 常见问题与故障定位

## 需要注册账号吗？

0.1.0 不需要账号。使用获准使用的连接证书，或设备 ID 加一次性临时密码即可访问。设备 ID 本身不授予权限。当前没有同账号设备自动发现或跨端设备清单同步。

## 为什么浏览器里的终端不可用？

浏览器仅预览界面。目录读取、PTY、SSH、设备认证及凭据管理由 Tauri 原生后端执行，需要使用 Mac App。

## 服务运行中，但另一台机器连不上

按顺序检查：

1. 双方是否填写同一个可访问的中继地址？两台机器不能分别用 `127.0.0.1` 表示同一中继。
2. WSS 证书是否受系统信任？代理是否转发 `/agent/ws` 与 `/client/ws` 的 WebSocket Upgrade？
3. 如果中继启用了 `UNIRC_TOKEN`，双方是否使用正确的中继准入令牌？它不能代替设备密码。
4. Agent 是否完成签名注册？其 `status` 中的设备 ID 是否与主机记录一致？
5. 证书是否已轮换，临时密码是否已使用、过期或被重新生成？

服务进程运行、或中继 `/health` 返回成功，都不能代替真实终端连接验收。

## 临时密码为什么不能重连？

临时密码在首次认证成功时消耗，只授权当前访问。该访问可以包含多个终端，但最后一个终端关闭、断网、退出应用或停止 Agent 后，旧密码不能重连。重新生成后再连接。

有效分钟数只限制首次认证时间，不会在到期时强制关闭已授权终端。需要立即结束访问时停止共享。

## 轮换证书后，旧终端为什么还可用？

轮换阻止旧证书建立新连接，已授权会话继续工作。导出新证书后更新主机配置；需要切断现有访问时停止共享或 Agent，再按需要启动。

## 提示凭据文件权限不安全

身份目录应为 700，身份文件和连接证书应为 600，并由实际运行软件的用户拥有。对你接收并保管的证书，可执行 `chmod 600 /absolute/path/device.shunyi-cert` 后重新选择。程序拒绝符号链接、其他用户所有或权限过宽的凭据文件。不要公开私钥或 `identity.json`。

## 提示已有 Agent 正在使用设备目录

检查是否同时启用了图形客户端共享和独立后台服务，停用其中一个。同一身份目录只允许一个 Agent，不应通过删除锁文件启动重复实例。

## 主机列表能看到所有人的设备吗？

不能。免账号客户端只展示用户保存的主机记录，支持类型、分组、名称筛选和显示选择。已保存但不可达的记录仍保留。当前没有匿名公共设备目录。

## 证书可以自动取得 root 吗？

不能。终端继承 Agent 的系统用户身份；普通用户 Agent 不会自动变成 root。需要 root 时由设备管理员配置运行用户，获准连接的人将拥有该服务用户的终端权限。

## SSH 提示未知主机或密钥改变

客户端检查系统 `~/.ssh/known_hosts`。通过可信方式核对服务器指纹，再用系统 SSH 完成首次信任。密钥改变时确认服务器重装、地址复用或连接目标错误等原因，瞬移不会自动接受变化。

## Mac 提示开发者或公证信息

初始预发布包使用 ad-hoc 开发签名，尚未完成 Apple Developer ID 签名和公证。核对项目发布来源与 SHA-256；也可从源码构建。签名状态会在发布说明中注明。

## 如何报告问题？

普通问题使用仓库 issue，附系统与架构、软件版本、连接方式、复现步骤和脱敏的错误文本。不要提交密码、证书私钥、身份文件或完整生产配置。安全问题使用 [SECURITY.md](../SECURITY.md) 中的私密渠道。
